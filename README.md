# CRUD Operations Using React, Nodejs & Mongodb

## 🚀 Overview
This project demonstrates a **CRUD (Create, Read, Edit, Delete)** application using the MERN stack:
- **Frontend**: React.js
- **Backend**: Node.js with Express
- **Database**: MongoDB

Users can perform the following operations:
- **Create**: Add new records (e.g., users, tasks, or items)
- **Read**: View all records from the database
- **Edit**: Edit existing records
- **Delete**: Remove records from the database

---

## ✨ Features
- Responsive design for all devices
- RESTful API integration with backend
- Real-time updates using MongoDB
- User-friendly UI built with React

---

## 🛠️ Technologies Used
- **Frontend**: React.js, Axios, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Tools**: Postman, VSCode, Git
